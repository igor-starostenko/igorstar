v2.5.2 Release - Lighthouse Performance Auditing & Image Optimization

This PR merges the develop branch into master for the v2.5.2 release.

## Key Changes

### Lighthouse Performance Auditing
- Added GitHub Actions workflow for automated Lighthouse audits (.github/workflows/lighthouse.yml)
- Configured CI/CD to run Lighthouse tests in Docker container (Dockerfile with CHROME_PATH, headless mode)
- Added Lighthouse config for assert preset and filesystem output (lighthouserc.cjs)
- Added test infrastructure for Lighthouse audits (src/test/lighthouse.test.mjs)

### Image Optimization Improvements
- Fixed Next.js Image component warnings for width/height mismatch
- Resolved aspect ratio issues in Logo, Thumb components
- Added proper objectFit instead of height auto for consistent sizing
- Applied constrained thumbnail dimensions (800x450 max) in Article component

### Documentation & Configuration
- Updated AGENTS.md with graphify integration instructions
